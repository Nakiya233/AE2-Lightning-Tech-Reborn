- 保存的维持视图与临时界面切换分开；上传失败保留已付费样板；旧种子先返还再补料及返还受阻提示。
- 皮格米建筑方块与连接面板；附近玩家闪电彩蛋范围/显示限制；中文指南与终端美术。

- AppGen 条件配方与特殊流体条件配方沿用 Forge 条件/标签格式；AE2LT 自定义配方继续使用其既有 `id` 产物字段。
- 量子桥拆除后清理失效集群，并同步 AE2/WTLib 两层网格缓存，支持远端重建和本地接入点回退。

## 额外修复与核实

- 电磁炮：从超载处决换成多维处决后，即使存档残留百分比模式，也按多维模块支持的模式执行；覆盖工作台真实换装和 EHV3 对生物的命中。
- 彩虹：Forge 1.20.1 shader JSON 显式绑定 `Position`、`UV0`、`Color`，修复外壳透明、仅显示纹路。
- 彩虹与超维：注册 Forge `IClientItemExtensions` 自定义物品渲染器，验证放置、GUI、第一/第三人称手持画面。
- 超载 IO 界面：移除 1.21 样式的 toolbox 重复引用，避免 1.20.1 AE2 样式加载失败导致窗口打不开。
- 相位锁定：1.20.1 护甲 tick 使用分区内索引 `0–3`，原 `36–39` 校验会每 tick 删除并付费重建投影，直至缺能中断飞行。改为校验装备槽内的真实物品实例；原生 `Inventory.tick` 覆盖四个护甲槽及热键栏同索引副本。
- 相位生命周期：退出登录或玩家克隆时结束私有飞行控制，同时保留服务端权威装备仓库，避免遗留控制状态。
- 发行版客户端启动：`MEStorageScreen.renderSlot` 是原版方法的覆写，在 Forge 发行环境中名为 `m_280092_`。`BigTerminalAmountMixin` 必须对该方法生成映射，同时保持 AE2 的 `formatAmount` 调用不映射；原先整体 `remap = false` 会在正式 AE2 JAR 下阻断启动。补充生成 refmap 的回归检查，避免仅检查开发映射的 AE2 二进制而漏报。

## 版本边界

Useless Mod 的通用样板编辑、模具中心和对应 JEI 路由未加入 Forge：已核对该项目远端 `develop/1.20.1` 为 `b51eb2905613b9be24bf0d812789d682f2015105`，其中没有 `OmniversalPatternEncoding`、`AlloyFurnaceRecipeCatalog`、通用样板物品或模具中心。对接这些功能需要先移植外部模组本身。

1.21 的 Data Components、StreamCodec、RecipeHolder、WTLib API 拆分和独立图标注册使用 1.20.1 的 NBT、FriendlyByteBuf、Recipe 与原生 WTLib 接口实现。调试探针单独适配为 Forge 事件与原生菜单/按键，不进入发布 JAR。

## 验证入口

使用 Java 17，先在同级 Thunderbolt 仓库执行 `./gradlew publishToMavenLocal`。

```sh
./gradlew build runGameTestServer
./gradlew -I scripts/tianshu-workstation-test.init.gradle runGameTestServer
./gradlew -I scripts/alpha-feature-test.init.gradle runGameTestServer
./gradlew -I scripts/main-fixes-test.init.gradle runGameTestServer
./gradlew -I scripts/latest-alpha-test.init.gradle runGameTestServer
./gradlew -I scripts/phase-flight-lock-test.init.gradle runGameTestServer
```

- 默认 Forge 游戏测试：35 项通过；以下专项共 133 项不重复用例，合计 168 项。
- 工作站/JEI：12 项原生 GameTest，验证真实 ME、JEI 服务端转移、精确 NBT、原生点击/回调、共享窗口、磁铁和 WUT。
- 催化器/轨道炮/量子桥：29 项原生 GameTest，含完整加工周期、存档、堵塞恢复、反加速、实际伤害与资源结算、拆桥重连。
- 未安装的外部模组条件配方会跳过其专属生产周期；通用流体行为通过水/岩浆夹具验证。这些结果不等同于所有外部模组组合的游戏实测。
- 最新 main 修复：4 项原生 GameTest（配方数据包加载、真实登录同步包、非法数量拒绝、无线接入点真实菜单绑定）。
- 1216 项 JUnit 通过；发布 JAR 不包含 `src/jdb` 的专项回归和客户端探针。

- 最新 Alpha：74 项 GameTest，含采矿 30、IO 17、彩虹/配方加载 12、建筑 9、地面潜行 6。
- 相位专项：20 项 GameTest，其中 6 项地面潜行与上项重复；其余验证原生移动/传送入口、跨维度拦截、飞行权限交接、锁定装备保存/释放与退出清理。

客户端探针只能用于一次性测试世界，会替换测试区域、装备和库存。先将游戏测试世界复制到 `build/forge-client-<probe>/saves/BackportQA`，再运行以下命令。`<probe>` 支持 `mining`、`io`、`rainbow`、`phase`；JEI 专项关闭开发环境的 EMI 接管。

```sh
./gradlew -I scripts/latest-alpha-client-test.init.gradle \
  -Palpha_client_probe=rainbow -Penable_emi_runtime=false runClient
```

客户端以日志中对应 `*_QA PASS` 为准，不能只用 `runClient` 的退出码判定。采矿验证进度、4096 数量同步、矩阵和两类机器共享输出界面；IO 验证 53 槽、速率/状态同步、操作按钮与 JEI；彩虹验证三类物品视角、连续流动、99 种半砖状态和全部染料 JEI 布局。

相位客户端以真实装备、真实 ME 供能和按键输入验证：双击起飞、服务端/客户端穿墙、外部飞行位写入防护、Shift+Space 悬停、地面潜行、关闭穿墙、下界往返同步、撤销最后飞行来源和恢复真实护甲。完整背包 tick 的原生回归替代了两项只验证全局槽号的旧单元测试。

## 发行 JAR 三件套启动复核

使用官方 Forge 47.4.10、Java 17 和官方发行版 AE2 15.4.10，直接从 `mods` 加载 Thunderbolt 2.0.0、AE2LT 2.1.0、LTPP 1.2.0-beta.9 的完整 JAR。独立的一次性探针确认三个实际加载路径与版本、进入单人世界、采矿工厂/IO 端口/有线和无线打包样板供应器的服务端创建与客户端同步，以及正常保存退出。探针不随三件套交付。

此次重新构建的 JUnit 结果为 TB 855、LT 1217、LTPP 259，均通过；重新运行 LT 默认 35 项和 LTPP 批处理 13 项原生 GameTest。上文 168 项 LT 专项总数是 PR 回移阶段的验证范围，并非本轮全部重跑。

测试环境还加载了 WTLib、JEI、Jade、AdvancedAE、ExtendedAE、ExtendedAE Plus、AppliedFlux、Mekanism 等可选依赖。ExtendedAE Plus 1.5.5 的两条 `broadcastChanges` Mixin 有其自身的发行映射警告，ExtendedAE 的可选 EMC 掉落表在未装对应兼容模组时也有日志错误；联合启动和三件套探针仍通过，但不据此宣称这些外部功能均正常。
