# 过载 IO 端口

<BlockImage id="ae2lt:overloaded_io_port" scale="4" />

在存储元件与 ME 网络之间整批搬运资源。提供六个输入槽、六个输出槽，沿用 AE2 IO 端口的填充、清空和弹出设置，需要频道和网络供电。

## 搬运速率

每批处理一个资源种类，搬运量取决于源库存与目标可接受的容量，不再额外限制每刻物品数或流体量。同种 100 万物品可以一批搬完，100 万个不同种类仍需多批处理。

| 加速卡数量 | 每种间隔 |
| --- | ---: |
| 0 | 5 tick |
| 1 | 4 tick |
| 2 | 3 tick |
| 3 | 2 tick |
| 4 | 1 tick |

每次最多尝试一种，六个盘共享间隔并轮流处理，放不进去的种类也占用本次尝试。未扫描完的部分留到下个处理时机继续，不会反复从第一个种类开始。重复唤醒不会绕过间隔，停机期间不积攒补发批次。上述速率需要网络正常供电且有可用空间；受阻时降低重试频率。

每批开始提取前收取 **32 AE**，与资源数量无关，待机消耗 **4 AE/t**。目标在模拟后临时拒收时，该批次也可能已耗电。电量不足则等待，并预留网络下一刻的待机能耗。

存储接口单次数量使用长整数，最多传递 9,223,372,036,854,775,807 个原生单位；超过这个数量的库存继续分批搬运。此为接口数值范围，不是端口设置的每刻数量限速。

## 设置与自动化

* **清空**：存储元件 → ME 网络；**填充**：ME 网络 → 存储元件。
* 支持**空时弹出**、**满时弹出**、**完成一轮扫描且无资源可搬时弹出**。本刻预算耗尽不会提前弹出尚未处理完的盘。
* 红石卡支持忽略信号、高信号运行、低信号运行，占用五个升级槽中的一个；可同时安装四张加速卡，达到每刻一种的最高速率。
* 从端口本地方向的顶部、底部输入磁盘，其他四面提取完成的磁盘；旋转方块会改变实际方向。自动化输入只接受存储元件。
* 输出槽满时，磁盘留在输入槽等待；玩家仍可手动取盘。

物品、流体、LT 闪电均使用原生存储键。第三方磁盘经 AE2 存储元件接口工作，遵守对应磁盘的权限、过滤与容量限制。

## 异常退回

目标实际接收量小于模拟量时，余量优先退回来源。如果来源也拒收，端口会暂存余量并暂停新搬运，直到 ME 网络可以接收。存档和拆机均保留这部分资源，重新放置并接入有空间的网络即可继续退回；内存卡仅复制设置。

在闪电装配室制作，JEI 可查询配方。
