# 苍穹织雷

  <ItemIcon id="ae2lt:celestweave_oculus" />
  <ItemIcon id="ae2lt:celestweave_core" />

**苍穹织雷**是模块化护甲。每件护甲都有独立的 FE 缓存、网络绑定、核心槽与模块槽。

| 部件 | 护甲栏位 |
|------|---------|
| 苍穹织雷·瞳 | 头盔 |
| 苍穹织雷·心 | 胸甲 |
| 苍穹织雷·径 | 护腿 |
| 苍穹织雷·阶 | 靴子 |

## 装配

每件护甲都需要在 <ItemLink id="ae2lt:overload_device_workbench" /> 中单独装配：

1. 放入护甲；护甲会绑定到工作站所在的 ME 网络
2. 在核心槽安装 <ItemLink id="ae2lt:ultimate_overload_core" />
3. 安装 1 个可选能量模块，以及对应部件可用的功能模块
4. 穿戴护甲后，默认按 G 打开过载设备中枢，启用、停用或配置模块

每件护甲可以安装任意数量的兼容模块，但同类模块的安装数量与互斥关系仍然有效，且能量模块只能安装 1 个。未安装能量模块时，每件护甲可存储 10,000,000 FE。T1 / T2 / T3 能量模块会将护甲容量提升至 1,000,000,000 / 5,000,000,000 / 20,000,000,000 FE。

## 运行条件

模块只有在护甲已穿戴、安装核心、模块已启用时才会进入运行态。运行中的模块会消耗已穿戴苍穹织雷部件中的 FE，并通常从绑定 ME 网络中消耗闪电。

当 FE 或所需闪电不足时，对应效果无法维持。

## 头部模块

| 模块 | 作用 |
|------|------|
| 夜视模块 | 运行时持续维持夜视效果 |
| 水下呼吸模块 | 运行时持续维持水下呼吸效果 |
| 饱和模块 | 周期性将饥饿值与饱和度恢复至满值，恢复时消耗高压闪电 |

## 胸部模块

| 模块 | 作用 |
|------|------|
| 触及扩展模块 | 增加方块 / 实体交互距离，可配置为 1x、2x 或 4x |
| 矩阵护盾模块 | 免疫环境伤害并自动灭火，普通伤害约 80% 减免，硬伤害约 50% 减免 |
| 相位护盾模块 | 每击最多抵扣 1024 点伤害；每点抵扣消耗 20,000 FE 与 2 极高压闪电。上限内取消受伤，超限部分照常结算；不提供机制防护或自动灭火 |
| 反伤模块 | 将来自攻击者的部分伤害反弹，消耗 FE 与高压闪电 |
| 过载防护模块 | 相位护盾的升级，提供无承伤上限的护盾与免死；护盾和免死共享每 20 tick 的 20 GFE、16,384 极高压闪电费用上限 |
| 多维防护模块 | 提供无承伤上限的护盾与免死，两条路径都不检查也不消耗 FE / 闪电 |
| 净化模块 | 移除并阻止配置允许的状态效果；默认只处理负面效果 |
| 享辐模块 | 完全阻止新增辐射暴露并免疫辐射伤害；处于有效辐射环境时每秒恢复 1～5 颗心，强度随辐射等级提高 |
| 激光防护模块 | 完全吸收 Mekanism 激光；按当前 Mekanism 能量换算比例，将实际吸收的焦耳转化为 FE，依次充入胸甲与整套苍穹织雷 |
| 相位锁定模块 | 提供四个可独立开关的子功能：盔甲锁定、飞行锁定、阻止外力拉动、阻止外部传送，详见下文 |
| 过载内核模块 | 解锁整套护甲的闪电代偿；极高压闪电 不足时优先使用现有 极高压闪电，再按 16 高压闪电 = 1 极高压闪电 补足缺口 |

矩阵护盾、相位护盾、过载防护、多维防护属于同一防护组，同一件胸甲只能安装一种。过载防护由相位护盾升级，多维防护使用过载防护进行 Pigmee 转化。

旧存档的不死模块自动转换为过载防护，保留开关、配置和免死连击状态。旧胸甲若同时装有不死和相位（或矩阵）护盾，升级后的过载防护会吸收已安装的低级护盾。背包或容器中单独存放的相位护盾不会被消耗。

### 相位锁定

相位锁定模块以胸甲为控制器，在设备中枢中提供四个可独立开关的子功能：

* **盔甲锁定：** 将当前穿戴的整套苍穹织雷转移到玩家专属的四个私有相位槽；各护甲栏会显示相位锁定投影，表明你的对应护甲正由私有相位槽保管。真护甲在私有槽中照常运行，锁定期间新穿上的苍穹织雷部件也会自动纳入。投影没有附魔光效，无法取出或交易；单个投影被替换或移除时，消耗 1,000,000 FE 与 16 极高压闪电原位重建，支付失败则整体解除锁定并穿回全部真护甲。
`你可以理解为灵魂绑定`
* **飞行锁定：** 冻结当前飞行状态，使落地后不自动退出飞行，并拒绝外部系统改写。它同时识别运行中的创造/相位飞行模块、原版游戏模式飞行以及其他 Forge 模组恢复的 `mayfly` 权限，但自身不会授予飞行能力。
* **阻止外力拉动：** 拦截水流、风扇、击退等外部系统对移动的改写；玩家自身操作与装备提供的移动不受影响。
`具体例子：无视机械动力鼓风机的推拉`
* **阻止外部传送：** 拦截外部坐标改写、传送与跨维度切换；玩家正常移动不受影响。
`具体例子：无视混沌龙强行传送`

## 腿部模块

| 模块 | 作用 |
|------|------|
| 创造飞行模块 | 提供悬停与翼装滑翔，可配置速度与飞行惯性 |
| 相位飞行模块 | 提供悬停与相位翼滑翔；相位模式可选择关闭、仅创造飞行或创造加鞘翅 |

创造飞行与相位飞行属于同一安装组，护腿上只能安装其中一种。相位飞行安装后默认停用，需要在设备中枢中启用。

两种飞行模块共用原版式操作：空中单击空格展开翼装滑翔，快速双击空格切换悬停。滑翔时持续按住空格会沿视线方向推进；悬停时空格上升、Shift 下降。同时按住 Shift 与空格时垂直输入互相抵消，并对其他模组表现为潜行状态。悬停潜行时使用地面潜行速度（受潜行属性与移动辅助的潜行倍率影响），临时关闭惯性，松开方向键立即停止；结束潜行后恢复配置的飞行速度与惯性。只有相位飞行可配置相位模式：**关闭**只关闭穿墙而不关闭飞行，**仅创造飞行**只允许悬停穿墙并让滑翔保持正常碰撞，**创造加鞘翅**允许悬停与滑翔穿墙。飞行锁定由胸甲的相位锁定模块统一控制。

## 足部模块

| 模块 | 作用 |
|------|------|
| 冲刺模块 | 默认按 V 向视角方向冲刺，冷却 40 tick |
| 挖掘适应模块 | 减轻水下与空中挖掘惩罚 |
| 步行辅助模块 | 分别调节步行、奔跑、潜行速度（0.5×～4×）与自动爬坡高度（0.6～3 格） |

## 消耗说明

多数运行中的普通模块每 tick 额外消耗 1 高压闪电。创造飞行与相位飞行在移动时消耗更多高压闪电；相位模式实际穿行时改为消耗极高压闪电。矩阵护盾和净化在短时间内连续触发时，消耗会逐次提高。相位与过载护盾按固定 20 tick 窗口内最高一击补差额；相位窗口最多支付 20,480,000 FE 与 2,048 极高压闪电。过载护盾吸收的伤害仍按每点 20,000 FE 与 2 极高压闪电计费，每个固定 20 tick 窗口按最高一击补差额，普通伤害费用始终封顶于 2 GFE 与 1,024 极高压闪电，不增加死亡连击。只有死亡触发才递增档位：窗口内第 n 次死亡的费用上限为 min(2n GFE, 20 GFE) 与 min(1024n, 16,384) 极高压闪电，并按该档上限计费。护盾与免死共用已付额度，只补差额；例如护盾已付满 2 GFE 与 1,024 极高压闪电，首次死亡不再收费，第二次死亡才补至 4 GFE 与 2,048 极高压闪电。死亡达到更高档位也不会抬高普通伤害的费用上限。同一次伤害的重复回调不重复计费，直接死亡路径的同 tick 重入也只结算一次。死亡第 10 档 FE 封顶，第 16 档闪电封顶，此后仍完全防护且不再收取触发费用。连击不延长窗口，20 tick 到期后清空已付额度和死亡连击。胸甲安装过载内核模块后，整套护甲的 极高压闪电 缺口可以按 16 高压闪电 = 1 极高压闪电 代偿。
